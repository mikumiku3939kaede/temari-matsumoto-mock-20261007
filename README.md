# お食事処 手毬 — デザインモック

松本市島立のお食事処 手毬の静的ウェブサイトモックです。ログイン不要のGitHub Pagesプレビュー用に、HTML・CSS・JavaScript・生成画像のみを収録しています。

料理写真は公式Instagramと店舗紹介に掲載された実写真を使用しています。写真は過去の提供例であり、現在の献立・価格を示すものではありません。蕎麦の実写真は未取得のため、その1枚のみ生成画像を仮置きしています。写真の掲載元は [PHOTO_SOURCES.md](PHOTO_SOURCES.md) に記録しています。ロゴはユーザー提供のPNGです。店舗情報は提供されたInstagramプロフィールに基づきます。最新情報は [Instagram](https://www.instagram.com/temari.zama/) または店舗へご確認ください。

生成り色、深い緑、朱色のデザイン。モバイルナビゲーション、料理・営業時間の詳細表示、地図・電話・Instagramリンクに対応しています。
