# お食事処 手毬 — デザインモック

松本市島立のお食事処 手毬の静的ウェブサイトモックです。ログイン不要のGitHub Pagesプレビュー用に、HTML・CSS・JavaScript・店舗の実写真を収録しています。

写真は公式Instagram、店舗紹介、訪問者投稿の実写真11枚を使用しています。生成写真はありません。写真は過去の提供例であり、現在の献立・価格を示すものではありません。蕎麦はtan^2さんによる2024年7月の訪問写真です。写真の掲載元は [PHOTO_SOURCES.md](PHOTO_SOURCES.md) に記録しています。ロゴはユーザー提供のPNGです。店舗情報は提供されたInstagramプロフィールに基づきます。最新情報は [Instagram](https://www.instagram.com/temari.zama/) または店舗へご確認ください。

生成り色、深い緑、朱色のデザイン。モバイルナビゲーション、料理・営業時間の詳細表示、地図・電話・Instagramリンクに対応しています。
