# お食事処 手毬 — デザインモック

松本市島立のお食事処 手毬の静的ウェブサイトモックです。ログイン不要のGitHub Pagesプレビュー用に、HTML・CSS・JavaScript・生成画像のみを収録しています。

料理写真は生成イメージであり、実際の提供内容・価格を示すものではありません。店舗情報は提供されたInstagramプロフィールに基づきます。最新情報は [Instagram](https://www.instagram.com/temari.zama/) または店舗へご確認ください。

生成り色、深い緑、朱色のデザイン。モバイルナビゲーション、料理・営業時間の詳細表示、地図・電話・Instagramリンクに対応しています。
